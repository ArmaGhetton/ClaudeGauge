# ClaudeGauge

Виджет для рабочего стола Windows 11: показывает расход лимитов аккаунта Claude
и время до их сброса. Python + tkinter, без внешних зависимостей.

## Как работать с пользователем

**Пользователь не программист.** Никогда не описывай правку словами вроде
«добавь обработчик в конструктор». Всегда указывай:

1. Конкретный файл.
2. Точный фрагмент кода, который надо найти (целиком, с отступами).
3. Точный фрагмент, на который его надо заменить.

Проще всего отдавать файл целиком после правки, а список изменений приводить
отдельно — для тех случаев, когда пользователь захочет внести их вручную.

Общение на русском.

## Файлы

| Файл | Назначение |
|---|---|
| `ClaudeGauge.pyw` | Всё приложение в одном файле |
| `ClaudeGauge.bat` | Запуск без окна консоли |
| `ClaudeGauge.ico` | Иконка, ищется строго рядом с `.pyw` |
| `README.md` | Инструкция для пользователя |

Настройки и логи: `%APPDATA%\ClaudeGauge\` — `settings.json`,
`token_cache.json`, `error.log`.

## Откуда берутся данные

`GET https://api.anthropic.com/api/oauth/usage` — тот же источник, что у команды
`/usage` в Claude Code. Официально Anthropic его не документирует, он может
измениться в любой момент.

Обязательные заголовки: `Authorization: Bearer <token>`,
`anthropic-beta: oauth-2025-04-20` и `User-Agent: claude-code/<версия>`.
**Без User-Agent эндпоинт отвечает 429.**

Токен читается из `~/.claude/.credentials.json`, при истечении обновляется через
`https://console.anthropic.com/v1/oauth/token`. Перед первой записью в файл
создаётся резервная копия `.credentials.json.backup`.

**Минимальный интервал опроса — 120 секунд, по умолчанию 180.** Меньше нельзя,
эндпоинт начнёт отдавать 429. Обратный отсчёт до сброса считается локально
каждую секунду и запросов не тратит.

## Правила для текстов интерфейса

Интерфейс полностью на русском.

- Фразы и сообщения — с заглавной буквы и с точкой в конце:
  «Нет активного окна.», «Слишком частые запросы.»
- Подписи полей, кнопки, заголовки разделов, пункты меню — с заглавной буквы,
  но **без** точки: «Прозрачность», «Готово», «Выход».
- После разделителя `·` — всегда заглавная, это самостоятельная подпись:
  «Неделя · Все модели», «Сброс через 2 ч 14 мин · Сегодня в 19:00.»
- Названия месяцев и дней недели остаются строчными: «20 сен, вс, 19:00».
- Дата сброса форматируется по-разному в зависимости от лимита
  (`date_and_clock(dt, full_month=...)`): у сессии (5 часов) — короткий месяц
  и день недели, «20 сен, вс, 19:00»; у недельных лимитов (`UsageRow.weekly`) —
  полное название месяца через `·`, без дня недели: «20 сентября · 19:00».
  «Сегодня в 19:00» / «Завтра в 19:00» — общие для обоих случаев.

## Грабли, на которые уже наступили

**Кириллица в .bat.** Файл `ClaudeGauge.bat` обязан быть чистым ASCII с
переводами строк CRLF. Кириллица внутри ломает разбор: cmd читает bat по байтам
и на многобайтовых символах начинает выполнять куски строк. `chcp 65001` эту
проблему не решает, а усугубляет. В `.pyw` кириллица безопасна — его читает
Python, а не cmd.

**Пути с кириллицей в PowerShell.** У пользователя проект лежит в
`D:\Программы\Виджеты\ClaudeGauge`. Передавать такой путь в PowerShell через
командную строку нельзя — кодировка искажается. Функция
`create_desktop_shortcut()` пишет временный `.ps1` в UTF-8 **с BOM** и запускает
его через `-File`.

**Залипание старого текста.** Окно полупрозрачное, Windows рисует его слоем и
после уменьшения высоты оставляет прежние пиксели. После любого изменения
размера нужен `force_repaint()` — он вызывает `RedrawWindow` с `RDW_ERASE`.

**Переименование приложения.** `APP_NAME` задаёт папку в `%APPDATA%` и ключ
автозапуска в реестре. При смене имени добавляй старое в `LEGACY_APP_NAMES`:
оттуда переносятся настройки и удаляется устаревшая запись автозапуска, иначе
виджет запустится дважды.

**Потоки и tkinter.** Сетевые запросы идут в фоновом потоке, результат кладётся
в `queue.Queue`, а главный поток разбирает очередь методом `poll_results()`.
Вызывать методы Tk из фонового потока нельзя.

**Перетаскивание и `Toplevel`.** `SettingsWindow` тоже без рамки и тоже
перетаскивается, но перетаскивание нельзя вешать на сам `Toplevel` (`self`) —
он есть в `bindtags` вообще всех дочерних виджетов, и повешенные на `self`
`<Button-1>`/`<B1-Motion>` срабатывают поверх обработки клика у `tk.Scale`,
двигая окно прямо под ползунком. Поэтому весь контент лежит во внутренней
рамке `content` (у неё и паддинги, `configure(padx=..., pady=...)` не на
`self`), и перетаскивание вешается на неё и на строки/заголовки разделов —
обычные фреймы в `bindtags` детей не попадают.

**Подсказка под статусом.** `hint_label` в подвале виджета всегда `pack()`-нут,
даже с пустым текстом — так под однострочный статус зарезервирована вторая
строка и окно не меняет высоту при каждом обновлении. Не возвращай для него
`pack_forget()`.

## Структура кода

- `THEMES` — три темы: `dark`, `oled` (чистый чёрный), `light`.
- `ACCENTS` — палитра акцентных цветов.
- `DEFAULT_SETTINGS` — значения по умолчанию, они же список всех настроек.
- `TokenProvider` — получение и обновление токена.
- `UsageRow` — одна строка лимита: заголовок, проценты, полоса, подпись.
- `SettingsWindow` — окно настроек: без рамки (`overrideredirect`),
  перетаскивается мышью, открывается по центру экрана (`withdraw()` до расчёта
  координат и `deiconify()` после — иначе окно на миг мелькает не в том месте).
  Выбор темы/акцента больше не закрывает окно: карточки тем и точки акцентов
  перерисовываются на месте (`_repaint_theme_cards`, `_repaint_accent_dots`),
  а их фон/подписи используют замороженный на момент открытия `_chrome_theme`,
  а не живую `app.theme`.
- `Widget` — главное окно, без рамки, перетаскивается мышью.

Окно без рамки (`overrideredirect`), поэтому размер задаётся явно: после любого
изменения содержимого вызывай `fit_window()`, иначе оно не подстроится.

## Проверка после правок

Запуск: `python ClaudeGauge.pyw` из папки проекта — так видно текст ошибки.
Обычный запуск через `ClaudeGauge.bat` прячет консоль.

Что стоит проверить руками после изменений интерфейса:

- Переключение всех трёх тем и компактного режима.
- Смена масштаба — окно пересобирается целиком.
- Длинное сообщение об ошибке: текст должен переноситься, окно расти, а при
  возврате к короткому статусу — уменьшаться без следов старого текста.
- Перетаскивание мышью и меню по правому клику.
