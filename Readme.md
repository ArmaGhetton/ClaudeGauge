## ClaudeGauge — виджет лимитов Claude для Windows 11

*[Read this in English](Readme.en.md)*

Показывает на рабочем столе, сколько израсходовано от Ваших лимитов Claude и когда они сбросятся.

- **Сессия · 5 часов** — процент и точное время до сброса
- **Неделя · все модели** — недельный лимит, дата и время сброса
- **Неделя · Sonnet** и **Неделя · Opus** — отдельные недельные лимиты
- **Дополнительный расход** — если подключён extra usage

Внешне — тёмная или светлая карточка со скруглёнными углами в стиле Windows 11, без рамки, перетаскивается мышью.

## Установка

### Шаг 1. Python

Виджету нужен Python (в нём уже есть всё необходимое, никаких `pip install`).

Проверьте, установлен ли он: нажмите `Win + R`, наберите `cmd`, в открывшемся окне введите

```
python --version
```

Если видите номер версии (3.9 или новее) — переходите к шагу 2.

Если пишет, что команда не найдена — скачайте Python с https://www.python.org/downloads/
При установке **обязательно поставьте галочку «Add python.exe to PATH»** на первом экране.

### Шаг 2. Положите файлы в папку

Создайте, например, папку `C:\ClaudeWidget` и положите туда:

- `ClaudeGauge.pyw`
- `ClaudeGauge.bat`
- `ClaudeGauge.ico`

Все три файла должны лежать рядом. Без `ClaudeGauge.ico` виджет работает, но остаётся без иконки.

### Шаг 3. Вход в аккаунт Claude

Виджет берёт данные оттуда же, откуда команда `/usage` в Claude Code. Чтобы он видел Ваш аккаунт, нужен один раз выполненный вход в Claude Code:

```
npm install -g @anthropic-ai/claude-code
claude
```

Внутри Claude Code выполните `/login` и войдите под своей подпиской Pro или Max.
После этого появится файл `C:\Users\ВашеИмя\.claude\.credentials.json` — виджет читает токен именно оттуда и дальше обновляет его сам.

### Шаг 4. Запуск

Двойной клик по **`ClaudeGauge.bat`**.

Сразу после запуска стоит сделать ярлык: правый клик по виджету → «Создать ярлык на рабочем столе». Появится `ClaudeGauge` с нормальной иконкой, и дальше запускать удобнее через него — bat-файл больше не понадобится. Ярлык можно закрепить на панели задач или в меню «Пуск».

Своей иконки у bat-файлов не бывает: Windows рисует им общий значок для всех файлов этого типа, и поменять его можно только сразу для всех.

Виджет появится в правом верхнем углу экрана. Перетащите мышью куда удобно — позиция запомнится.

## Настройки

**Внешний вид**
- Язык — русский или английский
- Прозрачность — от 30 % до 100 %
- Размер виджета — от 80 % до 170 %
- Тема — тёмная, OLED (чистый чёрный), светлая, а также градиентные «Аврора» и «Закат»
- Акцент — шесть цветов
- Поверх всех окон
- Скрывать с панели задач — виджету не нужна своя кнопка внизу экрана
- Компактный режим — только сессия и недельный лимит
- Эффект стекла — карточка становится блюром рабочего стола позади окна, как во флаутах Windows 11. Использует недокументированный API Windows, может не сработать на некоторых сборках — тогда просто ничего не изменится
- Закрепить позицию — виджет перестаёт перетаскиваться, чтобы не сдвинуть случайно

**Данные**
- Показывать недельные лимиты Sonnet и Opus
- Показывать дополнительный расход
- Интервал обновления — по умолчанию 180 секунд
- Порог тревоги — при каком проценте полоса становится жёлтой (по умолчанию 80 %), выше 95 % она всегда красная
- Звуковой сигнал при достижении порога

**Система**
- Запускать при входе в Windows
- Обновлять токен доступа самостоятельно
- Своё поле для токена — если не хотите ставить Claude Code

Настройки сохраняются в `%APPDATA%\ClaudeGauge\settings.json`.

---

## Почему интервал 180 секунд

Эндпоинт, который отдаёт данные о лимитах, жёстко ограничивает частоту запросов. При интервале меньше двух минут он начнёт отвечать ошибкой 429 и виджет покажет «Слишком частые запросы». 180 секунд — проверенное безопасное значение, меньше 120 выставить нельзя.

Обратный отсчёт до сброса при этом идёт каждую секунду — он считается локально и запросов не тратит.

## Если что-то не работает

**«Не найден вход в Claude»**
Claude Code не установлен или в нём не выполнен `/login`. Пройдите шаг 3. Либо вставьте токен вручную в настройках.

**«Токен доступа устарел»**
Включите в настройках «Обновлять токен доступа самостоятельно» либо просто запустите Claude Code — он обновит токен сам.

**«Слишком частые запросы»**
Поднимите интервал обновления до 300 секунд.

**«Нет соединения»**
Проверьте интернет, VPN или корпоративный прокси.

**Виджет не запускается**
Запустите `ClaudeGauge.pyw` из командной строки командой `python ClaudeGauge.pyw` — увидите текст ошибки. Также загляните в `%APPDATA%\ClaudeGauge\error.log`.

## Важное про токен

Виджет читает `.credentials.json` Claude Code и при необходимости обновляет токен доступа. Перед первой записью он делает резервную копию `.credentials.json.backup` рядом с оригиналом.

Если после этого Claude Code вдруг попросит войти заново — просто выполните в нём `/login`, ничего не потеряется.

Токен никуда не отправляется, кроме серверов Anthropic. Весь код — в одном файле, его можно открыть Блокнотом и прочитать.
